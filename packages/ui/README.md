# @frontend-engineering-system-lyz/ui

Shared React UI components for frontend-engineering-system.

## Install

```bash
pnpm add @frontend-engineering-system-lyz/ui react react-dom
```

## Usage

```tsx
import { Button } from '@frontend-engineering-system-lyz/ui';
import '@frontend-engineering-system-lyz/ui/styles.css';

export function Example() {
  return <Button>Save</Button>;
}
```
